## Google Apps Script 예시
```javascript
function doPost(e) {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('신청내역') || SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  const data = JSON.parse(e.postData.contents);

  sheet.appendRow([
    data.submittedAt || '',
    data.source || '',
    data.studentName || '',
    data.school || '',
    data.grade || '',
    data.program || '',
    data.enrollmentStatus || '',
    data.parentPhone || '',
    data.studentPhone || '',
    data.notes || '',
    data.privacyConsent || ''
  ]);

  return ContentService
    .createTextOutput(JSON.stringify({ success: true }))
    .setMimeType(ContentService.MimeType.JSON);
}
```

### 1. 전화번호 앞자리 0 유실 수정
하이픈 없이 `01025815818` 로 입력하면 구글시트가 숫자로 변환하며 앞의 0을 버려

시트가 문자열로 인식하도록 합니다.

`script.js` 의 `formatPhone()` 처리 규칙

| 입력 | 전송 값 |
| --- | --- |
| `01025815818` | `010-2581-5818` |
| `010 2581 5818` | `010-2581-5818` |
| `1025815818` (앞자리 0 누락) | `010-2581-5818` |
| `0317943306` | `031-794-3306` |
| `0212345678` | `02-1234-5678` |
| 숫자가 없는 입력 | 입력값 그대로 (지우지 않음) |

- 제출 시 `parentPhone`, `studentPhone` 에 적용
- `input[type="tel"]` 의 `blur` 시점에도 적용해 사용자가 정리된 형식을 확인 가능
- 형식을 알 수 없는 값은 입력값을 그대로 전송합니다.
  (빈 값으로 지우면 `api/submit.js` 의 필수값 검증에 걸려 접수가 거부됩니다.)

> 이미 시트에 숫자로 저장된 기존 행은 이 변경으로 복구되지 않습니다.
> 시트 쪽에서 별도 보정이 필요합니다.

### 2. 모바일 상단 고정 바 높이 축소
390px 기준 헤더 높이 **약 300px → 104px**.

원인은 두 가지였습니다.
- `@media (max-width: 980px)` 에서 `.quick-header-inner` 를 세로 배치로 바꿔
  브랜드 / 탭 / CTA 가 3단으로 쌓였습니다.
- `@media (max-width: 700px)` 의 `.quick-cta { width:100% }` 때문에
  CTA 가 전체 폭을 차지하며 한 줄을 더 썼습니다.

변경 내용
- 브랜드와 CTA 를 한 줄에 배치 (`flex-wrap` + `space-between`, CTA 는 `width:auto`)
- 탭은 `flex-wrap:nowrap` + `overflow-x:auto` 로 가로 1줄 고정
  (390px 이상에서는 스크롤 없이 6개가 모두 표시되고, 360px 에서만 가로 스크롤)
- 로고 · 브랜드명 · 탭 글자 크기와 패딩 축소

## v9 변경 사항 (모바일 타이포그래피 · 레이아웃 점검)

Noto Sans KR 을 실제로 적용한 상태에서 360 / 390 / 430 / 768 / 1280px 을

### 1. 한글 단어 중간 줄바꿈 (가장 광범위한 문제)
`body` 에 `word-break: keep-all` + `overflow-wrap: break-word` 적용.
기존에는 어절 중간이 끊겨 아래처럼 읽혔습니다.

| 위치 | 수정 전 | 수정 후 |
| --- | --- | --- |
| 히어로 배지 | `… 12월 31일 · 26` / `석 한정` | `26석 한정` 유지 |
| CTA 제목 | `3기 멤버십을 예` / `약하세요.` | `예약하세요.` 유지 |

### 2. 히어로 부제 문장 정리
강제 `<br />` 가 모바일에서 짧은 고아 줄을 만들고 `—` 가 문장 중간에
매달려 있었습니다. 줄바꿈을 제거하고 문장을 다듬었습니다.

- 변경 전: `… 진학 코칭은<br />목동유쌤영어학원이 — 두 곳이 연계해 …`
- 변경 후: `… 진학 코칭은 목동유쌤영어학원이 맡아 학기 중 자습 시간을 관리하는 프로그램입니다.`

### 3. 지표 카드 1단 → 2단 (모바일)
`@media (max-width: 700px)` 에서 `.stats-grid` 가 `1fr` 로 내려가
지표 4개가 세로로 쌓여 약 900px 를 차지했습니다. 2단 배치로 복구하고
여백 · 글자 크기를 줄여 약 500px 로 축소했습니다.
라벨 글자 크기를 13px 로 낮춰 `참여 학생 평균 등급 변화` 가 1줄에 들어갑니다.

### 4. 개인정보 고지 박스 (모바일)
`수집 항목` 등 라벨이 `min-width:112px` 인라인 블록이라 좁은 화면에서
라벨과 내용이 한 줄에 눌려 읽기 어려웠습니다. 모바일에서는 라벨을
윗줄로 분리했습니다.

### 5. 앵커 이동 시 제목이 상단 바에 가리는 문제
`section[id], header[id]` 에 `scroll-margin-top` 추가
(데스크톱 88px / 모바일 116px). 탭을 눌러 이동하면 섹션 제목이
헤더 아래 약 77px 여백을 두고 표시됩니다.

### 6. 비교표 가로 스크롤 안내
표가 `min-width:840px` 라 모바일에서는 첫 열만 보이고 상품별 금액이
보이지 않는데 스크롤 가능하다는 표시가 없었습니다. 모바일에서만
`표를 좌우로 넘겨 상품별 내용을 확인하세요 →` 안내를 표시합니다.

### 7. 그 외 모바일 글자 크기 조정
- `.manage-card h2` 32px → 27px (2글자 제목이 과도하게 컸음)
- `.schedule-day` → 20px, `.quote` → 1.3rem, `.intro-text` → 16px

전 구간(360 · 390 · 430 · 768 · 1280px)에서 가로 넘침이 없음을 확인했습니다.

## v11 변경 사항 (모바일 추가 수정)

### 1. 히어로 배지 줄바꿈
글자 크기를 13px → 12px 로 줄였고, 배지 내용을 의미 단위 조각으로 나눠
각 조각에 `white-space: nowrap` 을 적용했습니다.

- 변경 전: `… 12월 31일 · 26석` / `한정` (날짜·좌석 표기가 갈라짐)
- 변경 후: `BEYOND 3기 멤버십 모집 · 10월 19일 ~ 12월 31일 ·` / `26석 한정`

> 1줄 표시는 불가능합니다. 문구 길이 때문에 10.5px 까지 줄여도 360~430px
> 에서 2줄이며, `BEYOND` 를 빼고 날짜를 `10/19 ~ 12/31` 로 축약해도 2줄입니다.
> 1줄로 만들려면 8px 수준이 되어야 해서 읽을 수 없습니다.
> 대신 끊기는 위치를 통제해 `26석 한정` 이 갈라지지 않게 했습니다.

### 2. 동의 체크박스 텍스트 겹침 (iOS Safari)
`input[type=checkbox]` 가 `appearance: auto` 상태여서 iOS Safari 가
`width`/`height` 를 무시하고 자체 크기로 렌더링해 옆 텍스트를 덮었습니다.
(Chromium 에서는 18×18 로 정상 렌더링되어 재현되지 않던 문제입니다.)

`appearance: none` 으로 네이티브 렌더링을 끄고 체크박스를 직접 그리도록
변경했습니다. 브라우저와 무관하게 20×20 으로 고정됩니다.

- 테두리 + 라운드 박스, `:checked` 시 내부 사각형 표시
- `:focus-visible` 아웃라인 유지 (키보드 접근성)

### 3. 비교표 글자 크기 축소 (모바일)
첫 열이 화면을 거의 다 차지해 다른 열이 보이지 않던 문제를 완화했습니다.

- 본문 16px → 13px, 셀 여백 `14px 16px` → `11px 12px`
- 그룹 행 16px → 12.5px, 헤더 16px → 14px
- 각주 → 12.5px, `추천` 배지 → 10px

### 4. 푸터 사업자 정보 글자 크기 축소 (모바일)
법적 고지 영역이라 본문과 같은 크기일 필요가 없습니다.

- `.footer-bottom p` 14px → 11.5px (`line-height` 1.65)
- `개인정보처리방침` 링크는 탭 가능하도록 12px 유지

360 · 390 · 430 · 768 · 1280px 전 구간에서 가로 넘침 없음과
체크박스 겹침 없음을 확인했습니다.
